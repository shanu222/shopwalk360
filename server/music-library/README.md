# ShopWalk 360 music library

Original ambient tracks composed for ShopWalk 360 by `compose.py` (pure synthesis,
no samples or third-party recordings), so the store may play them publicly.

| File | Title | Style |
|---|---|---|
| golden-hour.mp3 | Golden Hour | warm electric piano over lush pads |
| gallery-walk.mp3 | Gallery Walk | mellow lo-fi, felt piano, soft beat |
| morning-atrium.mp3 | Morning Atrium | airy pads with wind-chime bells |
| velvet-evening.mp3 | Velvet Evening | slow bossa-tinged groove |
| lantern-light.mp3 | Lantern Light | slow pads with soft bell melody |
| window-shopping.mp3 | Window Shopping | light lo-fi with a gentle swing |
| cloud-atrium.mp3 | Cloud Atrium | dreamy beatless ambient |
| afterglow.mp3 | Afterglow | warm soul-tinged electric piano groove |
| silk-breeze.mp3 | Silk Breeze | flowing plucked arpeggios |
| citrus-morning.mp3 | Citrus Morning | bright, upbeat arpeggios |
| marble-hall.mp3 | Marble Hall | sparse piano in a big hall |
| rooftop-garden.mp3 | Rooftop Garden | easy groove with chimes |
| quiet-boutique.mp3 | Quiet Boutique | minimal, intimate piano |
| evening-promenade.mp3 | Evening Promenade | relaxed evening lo-fi with bells |

Each track is added to Admin → Store Music once (new tracks are added on the next start). Admins can hide,
reorder or delete them like any uploaded track. Regenerate with
`python3 compose.py <out_dir>` and `python3 compose2.py <out_dir>` (needs numpy, scipy and ffmpeg).
